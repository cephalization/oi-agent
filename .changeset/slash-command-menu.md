Slash commands get a completion menu: type `/` to browse, tab to complete, enter to run. New commands: `/resume` switches to a previous session, `/new` starts a fresh one, and `/model` switches model from a picker of the models your key can use. With the menu closed, tab toggles asking before tools, and shift+tab cycles reasoning effort through the levels the model supports. The status line shows both. API errors now show the API's own message.
